# BalloonShop

Веб-сайт розничной сети магазинов шаров на ASP.NET MVC.

## Функционал

**Сотрудник:**
- Просмотр каталога товаров с фильтрацией
- Оформление продаж
- История продаж
- Просмотр начисленной зарплаты

**Администратор:**
- Управление товарами (CRUD)
- Управление магазинами (CRUD)
- Управление сотрудниками (CRUD)
- Управление поставщиками и категориями
- Расчёт заработной платы

## Технологии

- C#, ASP.NET MVC
- Entity Framework Core 8.0
- SQL Server (InMemory для разработки)
- Bootstrap

## Запуск локально

```
dotnet restore
dotnet run
```

Сайт будет доступен по адресу `https://localhost:5001`.
